# 更新记录

## 0.2.0（2026-11-18）

- Windows 设置页增加版本检查、更新详情和下载进度。安装版使用与当前安装类型一致的签名更新包，并在交给安装器前备份本地扫描记录。
- 新增 Linux x64 命令行入口，可分析目录或 ZIP、输出机器报告，并按严重度设置质量门禁。
- 历史报告支持 SARIF 2.1.0，可将问题位置与规则导入支持该格式的工具。
- GitHub Release 随包提供 SHA-256 校验清单、许可声明与构建来源证明。

## 0.1.1（2026-11-18）

- 修复从总览重新打开当前扫描快照时，问题清单、评分和分析器结果被清空的问题。
- 修复重复导入同一项目时，历史快照从报告页消失的问题。原有扫描及报告选择会保留，导入预览会刷新。
- 修复原始项目路径失效后无法打开历史快照的问题。原先保存的报告仍可查看、比较和导出。

## 0.1.0（2026-11-18）

- 导入 Windows 本地目录和 ZIP，查看语言、框架、项目清单和扫描进度。
- 按严重度、语言、文件与模块筛选问题，展开源码上下文和定位证据。
- 查看注释、重复代码与静态依赖关系，使用覆盖率、置信度和未评估项解释健康度。
- 保存与比较多个项目的扫描快照，生成全面、重点、定点或基于历史基线的增量治理任务书，并导出报告。
- 保存主题、复杂度阈值和排除目录，按需启用已安装的 Ruff。
