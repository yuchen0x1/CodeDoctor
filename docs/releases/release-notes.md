# 更新记录

## 0.2.3（2026-11-21）

- 桌面与 CLI 共享的 SARIF 2.1.0 导出增加 `ruleIndex`、扫描完成标记和规则版本；保留现有规则 ID、严重度和非空指纹。
- SARIF 导出不再把未知行号写成第 1 行；不输出未转换的字节列，并继续使用编码后的项目相对路径，不嵌入源码证据或扫描配置。
- 修复报告保存对话框的竞态：等待期间锁定该表单、阻止重复打开；切换项目后丢弃旧结果和错误。取消或失败后可重试。
- 持久保存长度受限且清理控制字符的扫描失败诊断；重开失败任务仍可查看原因并按原设置重试。旧任务缺少诊断时显示兼容提示。
- 为源码预览增加 Python 三引号、JavaScript/Go 反引号和 YAML block scalar 凭据延续行遮蔽，并修复 TypeScript/Python 类型注解被误作值分隔符的遗漏，兼容 Python `r`/`u`/`b`/`f`/`t` 前缀、大小写组合及括号换行形式，保留 Go `:=` 及 YAML 注释含等号时的行为。
- 预览与内置逐文件规则共用敏感行判断，防止识别到的多行凭据续行作为超长行等问题的证据落库或导出；规则缓存升级为 `rules-4`，不复用旧语义结果。仍保留问题和定位，不批量改写历史记录。此为保守启发式遮蔽，不替代完整的秘密检测。
- 安全提示：旧历史、缓存、已导出报告和已生成任务书不会被追溯清理。请重新扫描，分享前检查；曾分享真实凭据时，应按自身流程撤回并轮换凭据。
- 保持 CLI 报告格式和退出码语义。v0.2.2 数据库会自动执行仅增加可空诊断字段的迁移；SARIF 不包含此诊断。缺少有效位置的发现可能无法创建行级注释；现有指纹不是 GitHub 行哈希。
- 安装与升级：Windows 安装版可通过签名更新或对应的 EXE/MSI 升级；免安装版和 Linux CLI 请先校验 SHA-256，再替换旧文件。迁移保留既有项目、扫描和缓存数据。

## 0.2.2（2026-11-21）

- 修复 Windows NSIS/MSI 安装升级测试的启动竞态：等待旧版初始化 SQLite，并验证新版恢复中断的扫描、保留旧库数据。`v0.2.1` 仅有源码标签，未公开发布安装包；以下改动随本版交付。
- 修复文件末行未换行时列号被压到第 1 列的问题，递增规则版本以避免复用旧位置缓存；历史快照不回写修改。
- 修复启动项目恢复覆盖手动导入的竞态；后台刷新保留有效的历史比较和报告导出选择，并防止显示与所选快照不符的比较结果。
- 问题清单与评分独立加载，评分保存失败时仍可查看已读取的问题，加载失败后可直接重试。
- 补齐 `.cts`、`.pyw`、`.pyi`、JSON 和 Dockerfile 的问题语言分类，避免筛选和导出遗漏。
- 更新偏好在本地存储不可用时安全降级，非法时间戳不再无限期阻止自动检查。
- 升级 Tauri API/CLI 补丁版本，补充组件竞态测试、发布文档版本校验、Linux 依赖安全审计与隔离的 MSI 安装/升级冒烟测试。
- 隔离 ZIP 测试的临时目录，避免并行测试在时间戳相同时相互删除待测文件。此项变更仅涉及测试辅助代码。
- 统一浅色/深色语义 Token，修复架构图、筛选控件、警告和禁用状态的主题残留；补齐焦点、按下状态、长路径换行及短窗口布局。
- 改善问题展开、架构节点、设置错误和更新弹窗的键盘与无障碍语义；修复问题列表缩短后的分页空页，源码上下文读取失败可原地重试。
- HTML 报告改为无外部资源的完整中文文档，增加双主题、窄窗和打印样式，继续转义所有扫描数据。

## 0.2.0（2026-11-18）

- Windows 设置页增加版本检查、更新详情和下载进度。安装版使用与当前安装类型一致的签名更新包，并在交给安装器前备份本地扫描记录。
- 新增 Linux x64 命令行入口，可分析目录或 ZIP、输出机器报告，并按严重度设置质量门禁。
- 历史报告支持 SARIF 2.1.0，可将问题位置与规则导入支持该格式的工具。
- GitHub Release 随包提供 SHA-256 校验清单、许可声明与构建来源证明。
